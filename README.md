# Portal Fit

Portal de Serviços Digitais desenvolvido como Entrega 1 da disciplina, aplicando os conteúdos estudados até a Aula 6: estrutura HTML, HTML semântico, navegação entre páginas, formulários, fundamentos de acessibilidade e CSS inicial.

## Sobre o projeto

O Portal Fit é um site fictício de serviços de academia, com planos de treino personalizado, avaliação física e acompanhamento nutricional.

## Estrutura do projeto

```
Portal_Fit/
├── index.html        # Página inicial
├── servicos.html      # Página de serviços
├── contato.html       # Página de contato (com formulário)
├── css/
│   └── style.css      # Estilos do site
└── img/
    └── treino-hero.svg # Imagem ilustrativa da página inicial
```

## Funcionalidades da Entrega 1

- Estrutura de projeto organizada em pastas (`css/`, `img/`);
- Três páginas navegáveis: início, serviços e contato;
- Menu de navegação funcionando entre as páginas;
- Uso de HTML semântico (`header`, `nav`, `main`, `section`, `article`, `footer`);
- Títulos, parágrafos, listas, links e imagem com texto alternativo;
- Formulário de contato com `label` associado a cada campo;
- Validação HTML básica nos campos obrigatórios (`required`, `minlength`, tipos `email`/`tel`);
- CSS inicial para identidade visual do portal.

## Tecnologias utilizadas

- HTML5
- CSS3
